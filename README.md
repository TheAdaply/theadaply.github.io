# theadaply.github.io

The re-forge landing page, served at <https://theadaply.com/> by GitHub Pages
from the `main` branch at the repo root. `CNAME` carries the custom domain.

Fully static: one page, one stylesheet, one small script, one logo, and the
machine-readable trust artifacts. No backend, no build step.

| File | Purpose |
| --- | --- |
| `index.html` | the page |
| `static/site.css` | all styling, including the rebuilt app frames |
| `static/site.js` | fits the app frames to their container and plays the hero's lineage animation once |
| `static/reforge-mark.png` | the mark |
| `FOR-AGENTS.md` | how an assistant should audit re-forge before a human installs it |
| `CAPTURE-MANIFEST.json` | machine-readable declaration of what is captured, sent, and never sent |
| `llms.txt` | orientation for language models |
| `CNAME`, `.nojekyll` | Pages configuration |

## Design notes (branch `v2`, 2026-09-07)

The product is the hero, and the page is built around one idea: selection.

- **Hero.** The Evolution view of the desktop app, rebuilt in HTML with the
  app's own tokens, with the lineage tree at the top and the captured data
  below it. The window dissolves into the page from 70% of its height down.
  On load a lineage graph grows out of the window's titlebar and forks
  generation by generation on shared arcs; one lineage is lit and marked
  "survives". The graph is generated by `site.js` from the measured layout,
  so it never touches the copy at any width. Behind it a small WebGL shader
  draws a slow, grainy field of paper, indigo wash and warm light.
- **How it works** is a scroll sequence: a sticky stage shows one generation
  happening (capture, generate, score, retire, specialise) as the five steps
  pass the middle of the viewport.
- **Motion tied to content only.** The two terminals race their timers once
  in view, the proof numbers count up once, and the product frames settle
  flat as they scroll in (GSAP ScrollTrigger from cdnjs; the page works
  without it).
- **Night bookend.** The final call to action and the footer share one dark
  background. The same generator grows a second lineage out of the footer
  wordmark, with the surviving agent in phosphor.
- Paper background, indigo accent, violet in the lineage gradient, ember
  only for retired candidates, amber only for upper bounds, green only for a
  winner. Fraunces for display, Inter for text, JetBrains Mono for data.
- The nav lifts into a floating pill after the first scroll.

Frames are drawn at 1120px and scaled with `zoom`. Below 62% they keep their
size and scroll inside their own wrapper, with an edge fade and a hint, so the
page itself never scrolls sideways. Reduced motion shows every graph and
counter in its final state, with the shaders frozen.

Every number in the proof strip is the same measured, detected, or
upper-bound figure the previous page carried, with the same labels. The mock
data inside the app frames is interface content, not a claim.

The previous page ("The hundredth time should be faster.", lifted from the
reforge-cloud dashboard) is in git history before this branch.

## Publishing

GitHub Pages serves `main` at the repo root; push to `main` and it redeploys.
To ship this branch:

```bash
git switch main && git merge v2 && git push origin main
```
