Inspect, evaluate and compare agent behavior.

Start with saved agent outputs. Read the score alongside the evidence. Then see a controlled regression show up in a comparison.

Start in Reforge Evaluations → Evaluations. In the project dropdown, choose Customer pilot — hosted workflow QA.

02 / Inspect
Actual trace evidence

Read the evidence behind the answer.

Click path: first sample → Open recorded root trace → expand Ava root → expand ava.reply → select products_in_category.

The basement answer gets the minimum-order arithmetic right: 259.71 × 6 = 1,558.26. But the lookup covered the powered category, while the answer made an unrestricted cheapest claim. That is a scope issue; it does not prove the quoted price was wrong.

The dryer comparison matches the checked facts. A relevance score of 1 does not resolve the scope issue.

Presenter notes

“The arithmetic is right. The lookup is narrower than the cheapest claim. Inspecting the trace reveals a question the relevance score does not answer.”

03 / Review
Relevance scorer

Know what the rubric measures.

Click path: Scorers → Ava — response relevance → Create new version to review criteria; close without saving for this demo.

Read the relevance rubric alongside the result. Relevance is not factual grounding or successful task completion: an answer can address the request and still need its claims checked.

Review the criteria and required evidence before saving a scorer.

Presenter notes

“The rubric determines what the score means. This evaluates relevance; factual grounding and task success need their own evidence.”

04 / Compare
Controlled synthetic regression

Make a known regression visible.

Click path: Experiments → search Core → Apply filters. Choose Core baseline — working Python and Core candidate — deliberate regression → Compare baseline and candidate → Regressions only.

In a separate controlled demonstration, the Core baseline scores 1 across 51 synthetic cases. A deliberately bad candidate scores 0 across the same 51 cases.

This demonstrates a controlled regression comparison on a separate fixture. It is not evidence of an Ava improvement, production reliability, or performance on unseen tasks.

Presenter notes

“Now we switch to a separate synthetic fixture. The candidate is deliberately bad. The comparison makes that known regression visible; it does not show Ava getting better.”
