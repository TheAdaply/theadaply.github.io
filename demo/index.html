The same question.
A policy-grounded answer.

Without the shop policy, the model suggests a refund may be possible. With the policy, it explains why the opened, working lamp is ineligible.

Six fictional Northstar Home support questions. Two real hosted runs using gpt-5.4-mini. The same instructions and questions; the second run adds the frozen shop policy.

In Reforge Evaluations → Evaluations, choose Support demo — policy before and after. Experiments → Baseline: Before — no shop policy → Candidate: After — shop policy supplied → Compare baseline and candidate.

01 / Before

A plausible answer can leave the wrong door open.

The customer asks:

My lamp arrived 10 days ago. I opened it and it works, but dislike the colour. Can you refund it?

Without the shop policy, the model says:

Since the lamp was delivered 10 days ago and it’s working, a refund may still be possible if it’s within our return window and the item is eligible for return.

The answer is qualified, but it does not identify the shop’s unopened-item requirement.

Presenter notes

Start with the actual customer question. The before answer leaves a possible refund path open because the model has not been supplied the shop policy.

02 / Change one input

Supply the rule the decision depends on.

The second run adds the same frozen policy to the system prompt. Its return rule is:

P1: Nondefective returns accepted only within 30 calendar days of delivery AND unopened; opened nondefective items ineligible.

The model, generic instructions, six questions, dataset revision and two scorer revisions stay the same. Each run generates one answer per question.

Read the full supplied policy and shared instructions
P1: Nondefective returns accepted only within 30 calendar days of delivery AND unopened; opened nondefective items ineligible.
P2: Manufacturing defects reported within 365 days qualify for warranty review, not an automatic refund; request order ID and a photo/video of defect; team determines repair/replacement.
P3: Expedited shipping fee refundable only if actual delivery was after confirmed promised date; verify promised+actual dates and expedited service; product price not refunded under this rule.
P4: Shipping address can be changed only before dispatch; after dispatch customer should contact carrier to request redirection, not guaranteed.
P5: Never claim an action has been completed; this assistant can explain/request evidence only. If eligibility facts missing, ask for them. All dates use elapsed days stated in question; no calendar arithmetic ambiguity.

Shared instructions:

You are a customer-support assistant for Northstar Home. Answer the customer clearly and concisely. Do not claim to perform actions you cannot perform.
Presenter notes

Only the frozen policy is added. For this lamp, the decisive fact is that a nondefective return must be unopened, even within 30 days.

Presenter notes

The raw means rise from 0.75 to one. That is a useful signal to inspect, not a claim of a 25-point accuracy gain. The table keeps all six cases visible.

04 / Inspect

The answer now applies the unopened-item rule.

In Search all comparison cases, type lamp; leave Regressions only unchecked. Expand Input / expected, then candidate Scores and rationale. The after answer says:

For nondefective items, we can only accept returns within 30 calendar days of delivery and the item must be unopened. Since the lamp was opened and it isn’t defective, it’s not eligible for a return/refund.

Both scoring dimensions give this case 0 → 1. The after rationale identifies the same policy reason: the lamp is opened and nondefective, so it is ineligible under P1.

Presenter notes

The answer change is the main result: it now explains the actual policy decision. Check the rationale rather than relying on the aggregate alone.
